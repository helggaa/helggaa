### 👨‍💻 About Me

Software developer with experience across **Machine Learning & Data Science**, **Modern Web & 3D Graphics**, **Backend Services**, and **Mobile App Development**. Focused on building performant web applications, statistical simulation engines, computer vision pipelines, and scalable software solutions.

- 🌐 **Web & 3D Engineering:** Building interactive browser applications with React, TypeScript, Three.js CAD rendering, and lightweight client-side tools.
- ⚙️ **Backend & APIs:** Developing RESTful backend services using Go and cloud automations with Google Apps Script.
- 📱 **Mobile Development:** Native Android application engineering using Kotlin and Java.
- 🎯 **Availability:** Open for software engineering, frontend/backend development, and data science opportunities.
